🧩 如何增量发布新材料到本站

本研习空间采用完全无后端的静态架构设计。当你在研学管理系统中导出某个新材料的【增量更新包 (.zip)】后，只需两步即可完成全站更新：

1解压并将新文档目录合并到 docs/ 文件夹

将 zip 包中的 docs/doc_xxxx 文件夹直接拷贝或上传至你 GitHub 仓库 / Cloudflare Pages / 服务器站点的 docs/ 目录下。

2复制 patch_entry.json 内容追加到根目录 docs.json

打开补丁包内提供的 patch_entry.json，复制其中的 JSON 块，将其追加粘贴到站点根目录的 docs.json 数组中：

// docs.json 示例 [ { "id": "doc_20260921_xxxx", "title": "新材料标题", "path": "docs/doc_20260921_xxxx/index.html", "flashcards_path": "docs/doc_20260921_xxxx/flashcards.html", "updated_at": "2026-09-21", "paragraph_count": 86, "flashcard_count": 32 }, // 👈 在这里追加新条目 ]
3刷新本首页

刷新本页面，新文档的研学阅读与考点闪卡即刻自动点亮并显示在导航大厅中，无需重装整站！
