# 🏛️ Omnididact 架构设计与技术全景白皮书

> **Omnididact**：全材料系统化自我教育与研学引擎（*The AI-Powered Self-Education System for Systematically Mastering Any Material*）

---

## 1. 系统核心设计理念

传统的学习工具有两大痛点：
1. **翻译与精读割裂**：普通的机翻工具缺乏上下文感知，容易丢失专业领域术语一致性，且长文档阅读时无法边读边追问；
2. **“读过即忘”缺乏内化闭环**：读者在阅读专业巨著或外文材料时，即使读懂了段落，也缺乏结构化的考点提炼与科学的记忆复现机制。

**Omnididact** 的核心使命是将任何复杂文献，通过全流程自动化与人机协同，转化为个人终身受用的知识库：
* **结构解析**：精准提取 PDF、DOCX、Markdown、TXT 的层级目录与图文排版；
* **双语精读**：句段级语义对齐、上下文滑动窗口翻译、保留强调标记；
* **深度伴读**：段落即时答疑、单章知识脉络梳理、研学注解沉淀；
* **科学内化**：自动提炼核心考点卡片，内置 SuperMemo SM-2 间隔重复记忆算法；
* **静态发布**：零依赖纯静态站点一键打包，支持 Cloudflare Pages / Nginx 多文档知识库大厅与增量补丁更新。

## 3. 核心子系统解析

### 3.1 文档多格式解析引擎 (`study/parser.py`, `doc_converter.py`)
- 支持 PDF 原生图文流式解析与目录树提取；
- 具备跨页断词（Hyphenation）自动缝合、行高分析识别主副标题；
- 复杂 Markdown 表格自适应渲染，支持图片 Base64 嵌入内联。

### 3.2 多模型接入层 (`providers/`)
- **OpenAI 兼容**：支持 DeepSeek, OpenRouter, Qwen, Moonshot 等全系兼容 API；
- **本地私有算力**：原生对接 Ollama、LM Studio，保障文献 100% 本地隐私；
- **云端服务**：支持 Cloudflare Workers AI、NVIDIA NIM、AMD AI 等；
- **插件扩展**：通过 `plugins/` 目录可零侵入热插拔私有网关或专有模型协议。

### 3.3 离线闪卡与 SM-2 记忆系统 (`templates/flashcards.html`)
- 纯前端单页应用（SPA），数据完整内嵌；
- 3D 卡片翻转交互、Cloze 挖空高亮遮蔽与逐个揭晓；
- 实现完整 SuperMemo SM-2 间隔重复算法，支持遗忘曲线智能调度复习。

### 3.4 纯静态知识库门户与增量 Patch 规范 (`templates/portal.html`)
- 数据驱动：根目录 `index.html` 动态读取 `./docs.json` 清单；
- 双向闭环：子文档支持一键返回知识库大厅；
- 增量发布：新文档导出增量 Patch 包，解压后仅需将 `patch_entry.json` 追加至根目录 `docs.json` 即可完成热更新。
